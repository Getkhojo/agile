# agiletechexpert.com

Website for **Agile Tech Experts Pvt. Ltd.** (brand: Agile Tech Expert).
Static multi-page site, generated by a small Python script. No framework, no Node build.

## Folder layout

```
content/            # ALL text lives here - edit these, then rebuild
  site.json         # company name, phones, email, address, social links, GA4, Search Console
  services.json     # 12 services: text, features, use cases, FAQs
  team.json         # team members (name, role, bio, photo, LinkedIn)
  gallery.json      # gallery photos and captions
src/assets/         # CSS, JS, background images; put team/ and gallery/ photos here
tools/build.py      # builds the site
public/             # BUILT SITE - this is what nginx serves. Commit it.
deploy/             # nginx config + deploy script
docs/BACKEND.md     # API the frontend expects (leads, logins, AI assistant)
```

## Edit and rebuild (Codespaces or any machine)

```bash
pip install pillow                 # once
python3 tools/build.py             # writes public/
python3 -m http.server 8080 -d public   # preview at port 8080
git add -A && git commit -m "Update content" && git push
```

Requires Python 3.12+.

### Common edits
- **Social links**: fill `social` in `content/site.json`. Empty ones are hidden.
- **Team**: fill `name`, `bio`, `linkedin` in `content/team.json`; photo goes in `src/assets/team/<file>.webp`, set `"photo": "<file>.webp"`.
- **Gallery**: drop photos into `src/assets/gallery/` and set `src` in `content/gallery.json`.
- **Google Analytics / Search Console**: set `ga4_id` and `google_site_verification` in `content/site.json`.

## Server setup (first time, Ubuntu + nginx)

```bash
sudo git clone https://github.com/Mkali10/agiletechexpert.git /var/www/agiletechexpert
sudo chown -R www-data:www-data /var/www/agiletechexpert/public
sudo cp /var/www/agiletechexpert/deploy/nginx-agiletechexpert.conf /etc/nginx/sites-available/agiletechexpert.conf
sudo ln -sf /etc/nginx/sites-available/agiletechexpert.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d agiletechexpert.com -d www.agiletechexpert.com
```

DNS `A` records for `agiletechexpert.com` and `www` must point to the server before certbot.

## Deploy updates

```bash
sudo bash /var/www/agiletechexpert/deploy/deploy.sh
```

## Google indexing checklist

1. Add `https://agiletechexpert.com` as a Domain property in Google Search Console (verify with the DNS TXT record).
2. Submit `https://agiletechexpert.com/sitemap.xml`.
3. Use URL Inspection on the home page and request indexing.
4. Create a Google Business Profile with the same name, address and phone as `content/site.json`.

`robots.txt` blocks `/portal/` and `/api/`; login pages are also `noindex`.
